02

PostgreSQL database for rice and corn drying service management

PrimeHarvest Grain Services

  • PostgreSQL
  • pgAdmin
  • SQL
  • ERD

PrimeHarvest Grain Services is an academic database project designed to manage rice and corn drying operations. Built using PostgreSQL, it organizes customer records, drying transactions, machine assignments, moisture readings, service rates, and payments.

Problem

Manual recordkeeping makes it difficult to monitor drying jobs, track grain weight and moisture levels, manage machine assignments, and maintain accurate payment records.

Solution

A centralized relational database that connects drying transactions with customer information, grain types, machines, service rates, and payments. It supports accurate recordkeeping, transaction monitoring, and operational reporting.

Stack

Database
PostgreSQL
Management tool
pgAdmin
Query language
SQL
Database design
Relational model and ERD

PostgreSQL was selected for its support for relational data management, constraints, and complex SQL queries. pgAdmin was used to create, manage, and test the database.

7interconnected tables

  • grain_types
  • drying_machines
  • service_rates
  • drying_jobs

  • payments

My contribution

  • Participated in planning and designing the relational database structure.
  • Contributed to creating the Entity Relationship Diagram (ERD) and defining table relationships.
  • Assisted in implementing database tables, primary keys, foreign keys, and constraints.
  • Developed SQL queries for retrieving drying transactions, calculating grain weight loss, and monitoring outstanding balances.
  • Participated in inserting sample records, testing database operations, and preparing project documentation.
